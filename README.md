# Code and analysis for: Rossiter et al. unpublished: *A novel approach to identify aquatic pollutants that could select for antimicrobial resistance: compound prioritisation for risk assessment research*

## Repository contents

This repository contains the final datasets, analyses and figures from the above-mentioned manuscript. It can be used to recreate figures and tables from both the main text and the supplementary files, with the following exceptions:

* All tables in Supplementary File 1 and Tables 1, 2, 3, 4, 6 and 7 from the manuscript, which were manually collated
* Tables S3.4, S3.5, S3.6, S3.7 and S3.8, in Supplementary File 3 which were generated using MarvinSketch
* Figure 2, which was created in BioRender.com.
* The Read me workbook for Supplementary File 2, which was added manaually

### **Script 1**

**Purpose:**
This script creates a PubChem reference table for the pollutants and antibiotics of interest, so that their SMILES strings can be used later to calculate physicochemical properties on Chemicalize.com. The script also separates compounds based on molecular weight, as we did not want to compute physicochemical properties for compounds with MW > 600 g/mol.

#### Workflow

1. The compound lists used in the study are defined, including:

   * pollutants of interest, the sources of which are referenced in the manuscript
   * antibiotics from O'Shea, Rosemarie, and Heinz E. Moser, *"Physicochemical properties of antibacterial compounds: implications for drug discovery," Journal of Medicinal Chemistry*, doi:10.1021/jm700967e
   * additional antibiotics from other sources, which are referenced in the manuscript

2. PubChem is searched using the `webchem` package to retrieve PubChem compound identifiers (CIDs) for each compound name.

3. Where PubChem does not automatically return a CID, the correct CID is manually added. This was required for Polymyxin B1.

4. Using the PubChem CIDs, the `webchem` package retrieves compound information from PubChem, including:

   * SMILES
   * molecular weight
   * CAS numbers

5. The `webchem` package is also used to retrieve PubChem synonyms for each compound. The first valid CAS Registry Number is then extracted where available.

6. The compounds are split into two groups based on molecular weight:

   * compounds with molecular weight <= 600 g/mol
   * compounds with molecular weight > 600 g/mol

Only compounds with MW <= 600 g/mol are taken forward for physicochemical property calculations. A molecular weight of 600 Da is numerically equivalent to a molar mass of 600 g/mol.

#### Information included in the PubChem table

The final PubChem information table contains:

* Compound name
* PubChem CID
* SMILES
* Molecular weight (g/mol)
* CAS number
* CAS number with dashes removed

The SMILES strings for compounds with MW <= 600 g/mol are used later for bulk upload to Chemicalize.com to calculate physicochemical properties.

### **Script 2**

**Purpose:**
This script uses the PubChem information generated in Script 1 to obtain physicochemical property predictions from Chemicalize and eNTRYway, and then combines these results with the PubChem information for later analysis.

#### Workflow

1. `Pubchem_Downloads.csv` is read in and compounds with MW <= 600 g/mol are selected.
2. SMILES and compound names are saved for bulk upload to [Chemicalize](https://chemicalize.com/).
3. The Chemicalize output is downloaded as an SDF file and read into R using the package `ChemmineR`.
4. The Chemicalize physicochemical properties are extracted and formatted.
5. SMILES generated by [Chemicalize](https://chemicalize.com/) are saved for bulk upload to [eNTRYway](https://entryway.igb.illinois.edu/).
6. The eNTRYway output is downloaded as a CSV file and read into R.
7. Compound names are checked and renamed where needed because spaces were removed during the upload process.
8. The PubChem, Chemicalize and eNTRYway information are joined by compound name and saved for use in Script 3.

### **Script 3**

**Purpose:**
This script uses the final joined PubChem, Chemicalize and eNTRYway output created in Script 2 and calculates additional physicochemical variables needed for the analysis.

#### Workflow

1. The final joined PubChem, Chemicalize and eNTRYway dataset from Script 2 is read into R.

2. Additional physicochemical variables are calculated, including:

   * interpolated logD at pH 7.4
   * relative polar surface area
   * hydrophilic compound classification
   * low globularity classification
   * low flexibility classification
   * eNTRY compound classification

3. Chemicalize bulk predictions only returned cLogD values at integer pH values, so logD at pH 7.4 is calculated by linear interpolation between logD at pH 7 and logD at pH 8.

4. Ionisation at pH 7.4 is described using compound net charge, and the major microspecies is defined as the species present at the highest fractional abundance at pH 7.4. As these values were not included in the Chemicalize bulk upload, they were manually transcribed from the Chemicalize web-based interface and joined into the main data frame.

5. For compounds ionised at pH 7.4 but lacking an amine, the presence of an ionisable nitrogen is also assessed manually. These manually checked functional-group assignments are then joined into the main data frame.

6. Compound use/class information is joined to the main data frame so that pollutants and antibiotics can be separated and summarised by compound class.

7. The final data frame is used to assign compounds into:

   * Group 1
   * Group 2
   * Group 3
   * No group

### **Script 4**

**Purpose:**
This script uses the final physicochemical information table created in Script 3, `Final_AB_Pol_Physchem_info.csv`, and adds chemical classification information from `ClassyFire`.

#### Workflow

1. `Final_AB_Pol_Physchem_info.csv` is read into R.

2. PubChem is searched using the `webchem` package to retrieve the InChIKey for each compound from its PubChem CID.

3. The InChIKeys are then used with the `classyfireR` package to retrieve chemical classification information.

4. The following classification levels are extracted:

   * kingdom
   * superclass
   * class
   * subclass

#### **Part 2. PERMANOVA of 8 physicochemical properties excluding molecular weight**

**Purpose:**
This part tests whether antibiotics and pollutants differ in multivariate physicochemical-property space using PERMANOVA, using `pairwiseAdonis` from the package `pairwise.adonis2`.

A combined grouping variable, `Group_type`, is created by combining compound priority group and compound type. For example:

* `Group_1_pollutant`
* `Group_1_antibiotic`
* `Group_2_pollutant`
* `Group_2_antibiotic`
* `Group_3_pollutant`
* `Group_3_antibiotic`
* `NG_pollutant`
* `NG_antibiotic`

The eight physicochemical variables are scaled and centred so that all properties contribute on comparable scales.

Euclidean distances are then calculated using the scaled physicochemical variables.

Before interpreting the PERMANOVA results, permutation-based tests of multivariate dispersion are carried out using `betadisper` and `permutest` from the `vegan` package. This checks whether significant PERMANOVA results could be influenced by differences in group dispersion rather than differences in group centroids.

Pairwise `betadisper` tests are then run for selected group comparisons, and adjusted p-values are calculated using the Benjamini-Hochberg method.
